# Korean Furniture Workshop Site

# Focus On Wood

React 기반으로 제작한 한국 가구공방 브랜드 사이트입니다.

공방 방문 없이 온라인에서 제품을 둘러보고 주문할 수 있도록 제작하였으며
원목 가구의 고급스러운 분위기와 브랜드 아이덴티티를 담는 것에 집중했습니다.

---

## 프로젝트 소개

기존 오프라인 중심의 주문 제작 방식을 개선하여  
사용자가 온라인에서도 편리하게 제품을 확인하고 주문할 수 있도록 구현했습니다.

브랜드 감성과 사용자 경험(UX)을 함께 고려하여 제작하였습니다.

---

## 주요 기능

- 메인 랜딩 페이지
- 브랜드 소개 페이지
- 제품 상세 페이지
- 주문 제작 UI
- 장바구니 UI
- 모바일 반응형 지원

---

## 사용 기술

- React
- Vite
- Tailwind CSS
- Framer Motion
- React Router

---

## 디자인 방향

- 원목의 따뜻한 질감 표현
- 미니멀하고 고급스러운 UI
- 자연스러운 애니메이션과 여백 중심 구성
